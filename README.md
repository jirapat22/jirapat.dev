# jirapat.dev

Pat's personal hub: a little solar system of the apps I build and use.

- `index.html` — the whole site (no build step). Edit the `APPS` list near the bottom to add an app or update commit counts.
- `CNAME` — tells GitHub Pages to serve this repo at jirapat.dev.

Hosted on GitHub Pages; every push to `main` goes live in about a minute.
